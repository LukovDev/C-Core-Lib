# C-Core-Lib

Ядро для любых программ на языке си.

Затачивается под кроссплатформенность.

Является расширением вокруг базовой стандартной библиотеки языка си, предоставляя дополнительный функционал, вроде динамического массива, хэштаблицы, времени, информации и так далее, упрощая разработку программ.

Ядро уже включает в себя стандартные библиотеки языка си, а также включает внутри себя дополнительные библиотеки для расширения своих возможностей, например `cglm`, `stb_image`, `stb_truetype`, `tinycthread`.

#

**Документация на данный момент отсутствует. Тестов и примеров также нет. Планируется в будущем.**

Доступные модули: `Array`, `Files`, `HashTable`, `Info`, `JobSystem`, `libs`, `Logger/log`, `math`, `mm`, `Node`, `Noise`, `Pixmap`, `PLATFORM`, `random`, `std`, `Time`.
