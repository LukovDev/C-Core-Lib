# JobSystem (`jobsystem.c`, `jobsystem.h`)

Модуль системы задач (пул потоков).

При инициализации создаётся по одному рабочему потоку (воркеру) на каждое логическое ядро процессора.

Воркеры спят и не нагружают процессор, пока нет задач.

Задача кладётся в очередь (первой пришла - первой выполнится), и система будит один спящий воркер.

Воркер забирает самую старую задачу, выполняет её и снова засыпает. Если все воркеры заняты, задача ждёт в очереди. Если каких-то воркеров не хватает, они досоздаются при следующей задаче.

Не подходит под мелкие задачи.
Задача не должна вызывать thrd_exit(), а долгие циклы лучше запускать отдельным потоком: такая задача навсегда занимает один воркер.

Указатель на функцию, которую мы будем выполнять:
`typedef int (*JobFunction)(void *args)`

Структуры:
```c
// Структура системы задач:
struct JobSystem {
    bool initialized;           // Инициализирована ли система задач.
    size_t workers_count;       // Сколько воркеров сейчас выполняют задачу.
    size_t max_workers_count;   // Сколько воркеров должно быть (по числу логических потоков процессора).
    size_t real_workers_count;  // Сколько воркеров сейчас живо.
    Array *queue;               // Очередь задач (в конец кладём, из начала забираем).
    mtx_t mutex;                // Мьютекс для защиты очереди и счётчиков.
    cnd_t cond_var;             // Условная переменная: на ней спят воркеры, пока нет задач.
};
```

```c
// Структура задачи:
struct JobTask {
    JobFunction function;  // Функция, которую мы будем выполнять.
    void *args;            // Аргумент задачи.
};
```

Глобальная переменная системы задач:
`JobSystem g_JobSystem;`

Функции:
- `void JobSystem_init(void)` - Инициализация системы задач. Вызывается при инициализации ядра.
- `void JobSystem_destroy(void)` - Уничтожение системы задач (ждёт, пока доработают выполняющиеся задачи, а задачи из очереди выкидывает). Вызывается при уничтожении ядра.
- `void JobSystem_create_job(JobFunction func, void *args)` - Поставить задачу в очередь.
- `bool JobSystem_has_active_jobs(void)` - Есть ли задачи в работе или в очереди.
- `size_t JobSystem_get_jobs_count(void)` - Получить количество задач в очереди.
- `size_t JobSystem_get_active_workers_count(void)` - Получить количество воркеров, занятых задачей.
- `size_t JobSystem_get_real_workers_count(void)` - Получить количество живых воркеров.
- `size_t JobSystem_get_max_workers_count(void)` - Получить сколько воркеров должно быть.
