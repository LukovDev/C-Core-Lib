# MM (`mm.c`, `mm.h`)

Модуль менеджера памяти.

Просто обертка над обычным malloc, но позволяет отслеживать использование памяти, и получать размер блока памяти. Отслеживание памяти является атомарным, что подходит для многопоточности.

Если выделяете кучу мелких объектов, то большую часть будет занимать заголовок. По этому рекомендуется выделять кучу мелких объектов одним вызовом чем по отдельности.

Рекомендуется использовать именно этот менеджер памяти, по разным причинам:
- Во первых, позволяет отслеживать сколько памяти используется этим менеджером.
- Во вторых, можно заменить аллокатор по умолчанию на другой (собственный) в файле `mm.c`:
```c
void* (*_m_alloc)   (size_t s)           = malloc;
void* (*_m_calloc)  (size_t c, size_t s) = calloc;
void* (*_m_realloc) (void *p, size_t s)  = realloc;
void  (*_m_free)    (void *p)            = free;
```
Как видим, по умолчанию используется обычный системный аллокатор. Можете подключить или написать собственный аллокатор и заменить функции выше.

Функции:
- `size_t mm_get_block_header_size(void)` - Получить размер заголовка блока в байтах.
- `size_t mm_get_allocated_blocks(void)` - Получить количество выделенных блоков.
- `size_t mm_get_absolute_used_size(void)` - Получить абсолютный размер используемой памяти в байтах с учётом заголовков блоков.
- `size_t mm_get_used_size(void)` - Получить сколько всего используется памяти в байтах этим менеджером памяти.
- `double mm_get_used_size_kb(void)` - Получить сколько всего используется памяти в килобайтах этим менеджером памяти.
- `double mm_get_used_size_mb(void)` - Получить сколько всего используется памяти в мегабайтах этим менеджером памяти.
- `double mm_get_used_size_gb(void)` - Получить сколько всего используется памяти в гигабайтах этим менеджером памяти.
- `size_t mm_get_block_size(void *ptr)` - Получить размер блока в байтах.
- `void mm_used_size_add(size_t size)` - Добавить байты к использованной памяти (атомарно).
- `void mm_used_size_sub(size_t size)` - Вычесть байты из использованной памяти (атомарно).
- `void* mm_alloc_aligned(size_t size, size_t alignment)` - Выделение памяти с явным выравниванием.
- `void* mm_alloc(size_t size)` - Выделение памяти.
- `void* mm_calloc(size_t count, size_t size)` - Выделение памяти с обнулением.
- `void* mm_realloc(void *ptr, size_t new_size)` - Расширение блока памяти.
- `char* mm_strdup(const char *str)` - Копирование строки.
- `void mm_free(void *ptr)` - Освобождение памяти.
- `void mm_alloc_error(void)` - Вызовите если получите проблему при выделении памяти.
