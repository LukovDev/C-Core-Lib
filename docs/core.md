# Core (`core.h`)

Ядро. Подключает все модули ядра здесь.

Является независимым пакетом полезных инструментов и функций, для любого приложения на си.

Функции:
- `bool core_init(void)` - Инициализация ядра (вызовите при старте программы).
- `bool core_destroy(void)` - Уничтожение ядра (вызовите перед концом программы).
- `const char* core_version(void)` - Получить версию ядра. Возвращает строку-литерал.
